RapidlyOn Admin Discovery email transport patch. ONLY for the Admin Discovery clarification and session confirmation routes. Install: npm install nodemailer && npm install -D @types/nodemailer. Add .env.local: SMTP_HOST=smtp.hostinger.com, SMTP_PORT=465, SMTP_USER=info@rapidlyon.com, SMTP_PASSWORD=<mailbox password>, DISCOVERY_NOTIFICATION_FROM=RapidlyOn <info@rapidlyon.com>. Ensure NEXT_PUBLIC_SITE_URL and LEAD_LINK_SECRET are already correctly set. Do not paste passwords into chat or commit .env.local. Run npm run lint; npx tsc --noEmit; npm run build. Other RapidlyOn email sending routes remain Resend-only and require separate migration.
